# ロビーと試合の操作

## プレイヤー

試合外では空き枠に「御伽のメニュー」コンパスが配られます。右クリック、`/otogi` または `/otogi menu` でロビーメニューを開きます。持ち物は上書きしません。満杯の場合は枠を空けると配られます。

どの画面もEscやEで閉じると、そのままゲーム画面に戻ります。開き直すと最初のロビー画面です。画面内の「戻る」ボタンで移動することもできます。

- **ビルド**: 試合で使う式・相・術・具を選びます。左クリックで追加、右クリックで解除します。ビルド画面のドアからロビーへ戻れます。
- **自分の戦績**: 通算撃破、死亡、試合数、勝利数、K/Dを表示します。`/otogi stats` でも確認できます。
- **遊び方・操作**: 参加待機や基本コマンドを確認できます。
- **試合に参加待機**: 次に管理者が始める試合への参加を予約します。押しただけで現在の試合へ入ることはありません。もう一度押すと待機から退出します。試合参加中は同じ場所が**試合から退出**に変わり、クリックすると退出します。退出した試合では勝利扱いになりません。
- **試合状況**: 試合の有無、参加者数、残り時間を確認します。

## 運営

`otogi.admin` 権限がある運営は、ロビーの**マップ・モード**から登録済みのマップとモードを選びます。試合開始時に参加するのは、参加待機中のプレイヤーだけです。待機者が2人以上のときに**待機者で試合開始**を押してください。稼働中の試合は同じボタンから終了できます。

コマンドでも状況確認と試合管理ができます。

- `/otogi game status` で試合状況を確認
- `/otogi game stop` で試合を終了
- `/otogi reload` で設定を再読み込み

### マップを登録する

マップは運営が建築した既存ワールドを使います。登録したいワールドで `/otogi map create <id>` を実行すると、現在のワールドをマップとして登録し、プラグインデータフォルダーの `maps/<id>.json` に編集用の定義を作ります。登録後にJSONで表示名、出現地点、範囲などを整え、`/otogi reload` で反映します。`/otogi map list` で登録内容を確認できます。ロビーのマップ選択から次の試合で使うマップを選んでください。マップ未登録でも「マップ・モード」画面の下部から登録済みモードを確認できます。

能力定義は `architects/*.json`、Luaの拡張処理は `architects/scripts/*.lua` で編集します。JSONはマップや能力のデータ、Luaは能力から呼び出す短い動作処理に使います。ファイルを編集した後は `/otogi reload` を実行します。定義の検証に失敗した場合、無効な内容は読み込まれず、エラー理由を案内します。

## 戦績の保存

戦績はプレイヤーのUUIDごとに `player-stats.json` へ保存されます。通常終了した試合は試合IDを記録し、同じ試合が終了処理から重複して届いても通算値を二重加算しません。途中退出者もその試合に参加した記録として集計されます。
