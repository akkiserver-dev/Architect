# 戦闘と当たり判定

## 操作と表示

具を持って左クリックで攻撃します。持ち替えても通常攻撃の待ち時間は共通です。
アクションバーの `▰▰▰▰▰` が満ちると、次の攻撃を出せます。
攻撃が通ったときは、相手の名前と実際に減らしたHPを短く表示します。
護符・鏡界・復帰時の加護で防がれた攻撃には、命中表示を出しません。

## 届く範囲

- 斬撃は視線に沿った扇の範囲です。表示される弧の端が射程です。
- 刀などは最初の相手1人に当たります。長柄の突きや細剣の貫通は直線上を狙います。
- 直線攻撃は視点の高さから出し、先端の小さな輪で幅を示します。
- 判定は相手の胴体の中心だけでなく、身体の端に触れた場合も調べます。
- 相手が近くても、背後を自動で巻き込む例外はありません。
- 遮蔽物で攻撃は止まります。演出も壁の先へ伸びないようにしています。

演出と判定は同じ射程・角度・発射位置を使います。
扇と四角いプレイヤーの身体が触れる判定には複数の表面サンプルを使います。画面上の粒子そのものに接触判定があるわけではありません。

## 調整

`plugins/Otogi/combat.yml` の `tools.<id>` で射程・角度・幅・攻撃間隔を調整できます。
変更後は試合終了を待って `/otogi reload`。

```yaml
feedback:
  sound: true
  particles: true
  volume: 0.7
  hit-marker: true
```

`particles: false` でも当たり判定は変わりません。
新しいJSON能力の設定方法は [JSON・Luaアーキテクト](../script-architects.md) を参照してください。
