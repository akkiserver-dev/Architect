# 修羅・背水 (shura)

状態: 実装済み（draftを先に作成、対人調整前）。修羅の苛烈さに着想を得た、傷を力に換える式。

## 操作と効果

装備中、受けるダメージは原因を問わず1.10倍。攻撃直前の現在HPが最大HPの40%以下なら、二次ダメージ以外の与ダメージを1.18倍にする。閾値は各ダメージイベントごとに判定し、持続状態やCTはない。

## 狙いと制約

高リスクの低体力攻撃。攻撃対象の低HPを見る首狩りや、被弾を条件にする八咫鏡・返照とは異なり、自分のHPを条件にする。追加攻撃や反射は発生せず、二次ダメージから効果を連鎖させない。解除・死亡時に残る一時状態はない。

## 運営の編集先

- 定義: `plugins/Otogi/architects/shura.json`（同梱元 `src/main/resources/architects/shura.json`）
- 実行: `plugins/Otogi/architects/scripts/shura.lua`
- `parameters.threshold` は最大HP比、`damage_bonus` は低体力時の与ダメージ倍率、`damage_taken` は被ダメージ倍率。説明文も数値と合わせて変更する。

## 検証観点

40%ちょうどで強化されること、HPが戻れば強化が消えること、環境ダメージにも被ダメージ倍率がかかること、二次ダメージで与ダメージ倍率が発動しないこと。
