# 一寸法師・寸鉄 (issun)

状態: 実装済み（draftを先に作成、対人調整前）。一寸法師の針に着想を得た、小さな隙を刺す式。

## 操作と効果

装備中の最大HPを10%下げる。最後に直接・範囲攻撃を命中させてから80tick（4秒）以上経つと、次の直接・範囲攻撃ダメージが1.15倍になる。命中した時点で待機時間を数え直す。装備直後も4秒待つ。二次ダメージには乗らない。

## 狙いと制約

常時加速する韋駄天や、被弾後の反撃を強化する八咫鏡・返照と異なり、攻撃間隔を空けて強い初撃を狙う。命中しなかった攻撃は時計を進めたままにする。解除・死亡時には最大HP補正と時刻を消し、再装備後は新しく待機する。

## 運営の編集先

- 定義: `plugins/Otogi/architects/issun.json`（同梱元 `src/main/resources/architects/issun.json`）
- 実行: `plugins/Otogi/architects/scripts/issun.lua`
- `parameters.health_penalty` は最大HP補正（負の割合）、`window` は待機時間、`multiplier` は次撃倍率。説明文も数値と合わせて変更する。

## 検証観点

装備直後に強化されないこと。4秒後の最初の命中にだけ倍率が乗ること。二次ダメージで時計が更新されず、死亡・解除で補正が消えること。
