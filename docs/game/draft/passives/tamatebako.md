# 浦島・玉手箱 (tamatebako)

状態: 実装済み（draftを先に作成、対人調整前）。浦島太郎の玉手箱に着想を得た、戦いの間を作る相。

## 操作と効果

装備後、直接・範囲の攻撃を命中させるか、環境以外の攻撃で被弾すると、待機時間を最初から数える。最後の命中・被弾から120tick（6秒）以上経ち、体力が満タンでなければ、自身を2HP回復する。回復後の内部CTは160tick（8秒）。命中・被弾で待機時間は延長されるが、内部CTは短縮されない。判定は20tick（1秒）ごと。

## 狙いと制約

攻撃を続ける鬼の血脈や、低体力時に継続回復する生気と異なり、戦闘が途切れた時だけ一度回復する。命中しなかった攻撃、環境ダメージ、二次ダメージは待機時間を更新しない。回復は自分だけ。死亡・解除・再装備時には時刻を初期化し、以前の待機・CTは持ち越さない。

## 運営の編集先

- 定義: `plugins/Otogi/architects/tamatebako.json`（同梱元 `src/main/resources/architects/tamatebako.json`）
- 実行: `plugins/Otogi/architects/scripts/tamatebako.lua`
- `parameters.quiet_ticks` は待機時間、`heal` は回復HP、`interval` は内部CT。`tickInterval` は判定間隔。説明文も数値と合わせて変更する。

## 検証観点

装備直後と命中・被弾後に即回復しないこと。6秒の静穏後だけ回復し、満タン時にはCTを消費しないこと。二次・環境ダメージは待機を延ばさず、死亡・再装備と別プレイヤーで状態が混ざらないこと。
