# 因幡・白兎 (inaba)

状態: 実装済み（draftを先に作成、対人調整前）。先にこの仕様を置き、JSON/Luaで実装する。

白兎を着想に、一撃を入れて身をかわす具。伝承の再現ではない。

- 左クリック: 射程2.8m・半角40度の扇形へ2.5HP。攻撃間隔16tick。
- 相手が生存する命中後、3秒間だけ右クリックで跳び退ける。
- 右クリック: 視線の水平向きへ速度1.05、上向き0.25で移動。CT7秒。移動は通常の物理衝突に従う。
- 成功時に権利を消費。窓切れや空振りではダッシュできない。
- 扇形の境界、命中時の準備通知、移動時の風の演出で操作結果を示す。
- 死亡・解除で準備状態が消える。

編集先: `plugins/Otogi/architects/inaba.json` と `scripts/inaba.lua`。数値はJSON、軽い条件判定はLua。試合終了後の `/otogi reload` で反映。

検証: 未命中での拒否、命中後の窓、期限切れ、ダッシュ失敗時の権利維持、死亡後の初期化、CTとの組み合わせ。
