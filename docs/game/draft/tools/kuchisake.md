# 口裂け・二口 (kuchisake)

状態: 実装済み（draftを先に作成、対人調整前）。口裂け女の都市伝説に着想を得た創作の具。

- 左クリック: 射程3m・半角35度の扇形に2.8HP。攻撃間隔18tick。防御を通り、相手が生存した命中で40tickの追撃権を得る。
- 右クリック: 追撃権がある間、射程6m・半径0.18mの直線で先頭の相手に4.5HP、押し出し0.2。CT120tick。
- 右クリックの判定前に追撃権を消費する。空振りでも発動とCTは成立する。権利の期限ちょうどでは発動できない。
- 左で間合いと照準を作り、短い窓で一人に追撃する。白兎のような移動効果はない。
- 死亡・解除で追撃権は消える。

編集先: `plugins/Otogi/architects/kuchisake.json` と `scripts/kuchisake.lua`。射程・角度・ダメージ・間隔・窓・CT・幅・押し出しと表示はJSONから調整する。試合終了後の `/otogi reload` で反映。

検証: 左空振り、命中後の追撃、窓の最終tickと期限ちょうど、右空振りの権利消費、CT、死亡後の初期化、所有者間の分離。
