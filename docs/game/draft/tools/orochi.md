# 八岐大蛇・蛇骨 (orochi)

状態: 実装済み（draftを先に作成、対人調整前）。先にこの仕様を置き、JSON/Luaで実装する。

八岐大蛇を着想に、間合いを詰めて牙を蓄え、一度に放つ具。

- 左クリック: 射程3.5m、半径0.35mの直線。先頭に3HP、攻撃間隔20tick。
- 命中して相手が生存すると牙が1つ増える。最大3つ。空振りでは増えない。
- 右クリック: 牙が必要。すべて消費し、自身の周囲3.5mへ `1 + 牙数 × 1.5` HP、押し出し0.35。CT6秒。
- 対象がいなくても放出は成立する。牙を使う判断と接近が必要。
- 短い射線と放出範囲を粒子で表示。死亡・解除で牙を失う。

編集先: `plugins/Otogi/architects/orochi.json` と `scripts/orochi.lua`。表示と全数値をJSONから変更できる。判定はJavaの共通API、蓄積と分岐はLua。試合終了後の `/otogi reload` で反映。

検証: 空振り、1/3牙での放出、上限、CT中の操作、死亡後の初期化、壁越しの対象除外、他プレイヤーとの状態分離。
