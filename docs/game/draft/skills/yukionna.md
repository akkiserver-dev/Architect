# 雪女・白息 (yukionna)

状態: 実装済み（draftを先に作成、対人調整前）。下記を先に定め、Javaの扇形判定・命中後の減速として実装する。

## 操作と効果

着想: 雪女の冷たい息。右クリックで目線に沿う射程6・半角32度の扇形へ3ダメージ。命中した相手へ60tickの移動速度低下Iを与える。CT180tick。扇形の外周と両端を少量の雪粒で示し、息を吐く短い音を鳴らす。着弾は共通ヒットマーカーで確認できる。

## 狙いと制約

追撃・離脱を助ける近距離の足止め。凍結、移動の完全停止、地形変更はしない。既存の目からヒットボックスへの扇形接触判定を使い、壁で遮られた相手には当たらない。同じアリーナの生存・非無敵の相手のみ最大16人。ダメージが無効化された場合や、その一撃で死亡/復活した相手には減速を付けない。効果時間は既存ポーション規則に従い、死亡時の戦闘リセットで除去する。

## 運営の編集先

`src/main/resources/architects/yukionna.json` → `plugins/Otogi/architects/yukionna.json`。backend=java、handler=frost_cone。parameters: range(0.1–16)、halfAngle(1–75)、damage(0.1–40)、slowTicks(1–200の整数)、slowAmplifier(0–2の整数; 0がI)。cooldownはtick。範囲外の値・未知のパラメーターは読み込み時に拒否する。試合外の `/otogi reload` で次試合から反映する。

## 検証観点

扇形の端・射程端・上下照準、遮蔽物、無敵とキャンセル、致死打撃後の減速なし、他プレイヤーや別アリーナとの混線なしを確認する。数値は実戦調整前の初期値。
