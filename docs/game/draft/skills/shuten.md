# 酒呑童子・鬼宴 (shuten)

状態: 実装済み（draftを先に作成、対人調整前）。下記を先に定め、Javaの期限付きダメージ補正として実装する。

## 操作と効果

着想: 酒呑童子の強さと酔いの隙。右クリックで80tick、具の直接ダメージ(TOOL)が1.3倍になる。同じ間、自分の全被ダメージが1.25倍になる。CT260tick。発動時に赤い粒子の輪・低い太鼓音・Adventureのアクションバー「鬼宴: 具威力↑ / 被ダメージ↑」、効果中は短い赤い輪、終了時に短い消灯音を出す。

## 狙いと制約

被弾を避けながら近接で押す短時間の勝負。術・範囲具・二次ダメージには攻撃強化を適用しない。防御能力と組み合わせても被ダメージ側の代償は同時に掛かる。効果中の再発動は不可。期限判定は各ダメージ時に行い、周期処理の遅れで延長しない。属性やポーションは変更せず、死亡・装備解除・退出・試合終了でプレイヤー別の効果状態を削除する。

## 運営の編集先

`src/main/resources/architects/shuten.json` → `plugins/Otogi/architects/shuten.json`。backend=java、handler=oni_frenzy。parameters: durationTicks(1–200の整数)、toolMultiplier(1–2)、incomingMultiplier(1–2)。cooldownはtick。範囲外の値・未知のパラメーターは読み込み時に拒否する。試合外の `/otogi reload` で次試合から反映する。

TOOLのみの強化、全被ダメージへの代償、期限直前/直後、複数装備者の独立、死亡/復活と装備解除での解除、CTが短く設定された場合の重ね掛け拒否を確認する。数値は実戦調整前の初期値。
