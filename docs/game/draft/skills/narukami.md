# 雷神・鳴神 (narukami)

状態: 実装済み（draftを先に作成、対人調整前）。下記を先に定め、Javaの照準固定・予告・命中処理として実装する。

## 操作と効果

着想: 雷神が打ち鳴らす一閃。右クリック時の目の位置・向きを固定し、20tick後に射程12、判定半径0.45の直線へ7ダメージ、ノックバック0.35。CT240tick。射線の始点・方向は発動後に追尾しない。全員に見える火花の線と終端の幅マーカー、短い予告音を出し、着弾時に音程の低い雷音へ変える。

## 狙いと制約

予告中に相手の退路を読んで置く術。相手は射線の横へ避けられる。射線は発動時の最初の壁までに固定し、着弾時にも壁を再確認する。判定は既存の拡張ヒットボックスによる直線判定で、同じアリーナの生存・非無敵の相手だけを対象に最大16人。雷エンティティや火、地形は生成しない。死亡・装備解除・退出・試合終了で予約を中止し、復活後へ持ち越さない。

## 運営の編集先

`src/main/resources/architects/narukami.json` → `plugins/Otogi/architects/narukami.json`。backend=java、handler=thunder。parameters: range(0.1–32)、width(0–2)、delayTicks(4–100の整数)、damage(0.1–40)、knockback(0–2)。cooldownはtick。範囲外の値・未知のパラメーターは読み込み時に拒否する。全件検証に成功した試合外の `/otogi reload` で次試合から反映する。

## 検証観点

予告と着弾の位置一致、予告中の移動と振り向き、壁の直前・直後、死亡/復活・退出・装備解除による中断、別アリーナ除外、予約の重複なしを確認する。数値は実戦調整前の初期値。
