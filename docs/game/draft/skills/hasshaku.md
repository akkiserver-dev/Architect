# 八尺様・呼び声 (hasshaku)

状態: 実装済み（draftを先に作成、対人調整前）。予告領域の仕様に沿ってJavaで実装。

都市伝説の不気味な呼び声を着想に、相手の逃げ先へ置く術。伝承の再現ではない。

## 操作と効果

右クリックで、視線の先10mまでの位置に半径2.5mの球形の領域を置く。照準は発動時に固定。途中に壁がある場合は壁の手前へ置く。

24tick（1.2秒）の予告後、その球に触れ、中心から遮蔽物のない相手へ4HPの範囲術ダメージ。ダメージが通って生存した相手の術を30tick（1.5秒）封じる。CT220tick（11秒）。既に長い封印がある場合は短縮しない。

予告は水平・垂直の輪郭を青い火で描き、設置時と発動時に異なる音を鳴らす。予告は4tick間隔、対象は最大16人。球の中は塗りつぶさない。球は使用者を追従しない。

## 制約と編集先

死亡・退出・装備解除・試合終了・ワールド移動で予約を取り消す。壁越しのダメージ、地形・エンティティの設置は行わない。無敵・防御で防がれた相手には封印しない。

`plugins/Otogi/architects/hasshaku.json` の表示・CT・parametersを編集し、試合外の `/otogi reload` で反映。

Java handler: `dread_sphere`。range 0.5〜24、radius 0.5〜6、delayTicks 整数8〜100、damage 0.1〜20、silenceTicks 整数0〜100。未知のパラメーター・範囲外値は読み込み時に拒否する。

## 検証

視線固定、壁手前への設置、球形輪郭、予告中の回避、致死・無敵時の封印なし、長い封印の維持、死亡後の予約解除と次の生存状態の予約保護を確認する。対人戦の数値調整は別途行う。
