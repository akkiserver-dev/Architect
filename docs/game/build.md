# 御伽 - ビルド

試合開始前に、使用するアーキテクトを組み合わせてビルドを組める。

## 操作

- `/otogi build` : ビルド選択メニューを開く。左クリックで選択、右クリックで解除する。
- `/otogi build show` : 現在のビルドを表示する
- `/otogi build reset` : ビルドを空にする

## 仕様

- 選べる数（枠）はゲーム設定で変動する。デフォルトは5個。（`config.yml` の `build.size`、1〜9）
- 式は1つのみ。相・術・具は種類を問わず、枠が許す限り自由に組み合わせられる。
  - 式を選んでいる間、他の式は選べない理由を赤字で表示する。右クリックで外してから選び直す。
- 枠がいっぱいの場合も、右クリックで外してから他を選ぶ。アイコンはそのまま、選択中のものはチェックと発光で表示される。
- 表示しきれない能力は、下段の矢印でページを切り替える。
- 同じアーキテクトは入れられない。
- 式に併用不可が設定されているアーキテクトは同じビルドに入れられない。
- ビルドが空の場合は、式1つ・具1つを含むランダムなビルドになる。
- ビルドはプレイヤーごとに `plugins/Otogi/builds.yml` へ保存される。試合中は変更できない。

# 攻撃判定

- 具はバニラの通常攻撃を使わない。手に持った具で左クリックすると、その具が独自の判定・エフェクト・ダメージを処理する。
- 具を複数持つ場合は、ホットバーの先頭から具、続いて術が並ぶ。持ち替えて使い分ける。
