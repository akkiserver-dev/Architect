# 御伽の能力図鑑

同梱の全54種を、式・相・術・具に分けて紹介します。説明はゲーム内の日本語原文です。
数値は同梱設定を前提とした表示です。サーバー独自の調整や翻訳変更がある場合は、ゲーム内の説明を確認してください。

CTは再使用までの待ち時間。2HP＝1ハートです。各項目のIDは術・具のお試し指定にも使えます。

[遊び方へ戻る](guide.md)

## 式 / 常時効果（11種）

### 金城 / `bulwark`

- 最大体力 +4 / ノックバック耐性 +20% / 移動速度 -5%
- 体力が最大の間、受ける最初のダメージを15%軽減
- 併用不可: 式「韋駄天」

### 導線 / `conduit`

- 術を当てると、次の通常攻撃のダメージ +25%
- 強化は5秒間 / 共鳴と併用不可

### 天女の羽衣 / `feather`

- 移動速度+12%
- 受けるダメージ+10%

### 研澄 / `focus`

- 8ブロック以内に敵がいなければ、術の射程 +10%
- 術を外すと次の術のダメージ +10% / 導線と併用不可

### 一寸法師・寸鉄 / `issun`

- 最大体力-10%
- 命中から4秒空けた次の直接・範囲攻撃が1.15倍

### 浮力 / `levity`

- 落下ダメージ無効 / 最大体力 -3
- 空中で敵を攻撃すると短時間移動速度上昇
- 併用不可: 式「金城」

### 共鳴 / `resonance`

- 術を当てると、次に使う術のCTを2秒短縮
- 8秒に1回 / 最大体力 -2 / 金城と併用不可

### 韋駄天 / `rush`

- 体力 -6 / 移動速度 +10% / 跳躍力 +10%
- 併用不可: 相「隠密」

### 修羅・背水 / `shura`

- 受けるダメージ+10%
- 体力40%以下で二次以外の与ダメージ+18%

### 金剛 / `tank`

- 最大体力 +4 / 移動速度 -5% / ノックバック耐性 +10% / 耐性Ⅰ
- 併用不可: 術「神隠し」

### 生気 / `vitality`

- 最大体力 +6 / 移動速度 -8%
- 体力が50%以下の間、自然回復量 +20%
- 併用不可: 式「韋駄天」

## 相 / 自動発動（15種）

### 残影 / `afterimage`

- 素早く移動した先に、2秒間の残像を残す
- 残像の体力4 / 壊した相手に2秒間の盲目 / CT 10秒

### 首狩り / `bounty`

- 体力が30%以下の敵へ与えるダメージ +10%
- その敵を撃破すると術のCTを3秒短縮

### 応報 / `counter`

- 先手を取られると、相手を2秒間暗闇とジャミングにする
- CT 10秒 / 同じ相手には20秒に1回

### 怨恨 / `curse`

- 倒されたとき、相手に10秒間の怨霊を残す
- 怨霊は発光と鈍足を与える / CT 40秒
- ジャミングを受けない

### 反響 / `echo`

- 受けた術ダメージの15%を、1秒後に相手へ返す
- CT 6秒 / 反響からは追加効果が発生しない

### 先見 / `foresight`

- 自分へ向かう投射物の軌道が、一瞬だけ見える
- 予兆から身をかわすと通常攻撃が再使用可能 / CT 12秒

### 件・凶兆 / `kudan`

- 体力30%以下で速度Iを3秒・耐性Iを1秒
- 1秒ごとに判定 / 内部CT15秒

### 送り犬・護り牙 / `okuriinu`

- 5秒以内に具ダメージを3回受けると耐性I・速度Iを2秒
- 術・二次・環境ダメージは数えない / 内部CT10秒

### 不死 / `resurrection`

- 試合中1回だけ死を免れる
- 体力が半分の状態で復活し、1秒間無敵

### 八咫鏡・返照 / `riposte`

- 被弾後4秒以内の次の直接攻撃が1.25倍
- 攻撃時に構えを消費

### 拾得 / `scavenger`

- 12b以内で敵が撃破されると術のCTを1秒短縮
- 自身が撃破した場合は追加で1秒短縮

### 鬼の血脈 / `siphon`

- 直接ダメージ命中で1HP吸収
- 内部CT2秒 / 二次ダメージは対象外

### 隠密 / `stealth`

- 攻撃を受けると一定時間透明になる
- 自分が攻撃・術を使う、または攻撃を受けると解除
- 透明中は自動回復しない / CT 30秒

### 浦島・玉手箱 / `tamatebako`

- 命中・被弾から6秒離れると自身を2HP回復
- 内部CT8秒 / 二次・環境ダメージは対象外

### 献上 / `tribute`

- 体力が20%減少するたび、術のCTを1秒短縮
- 1回のダメージで複数回発動しない / 自傷では発動しない
- 体力が最大まで回復すると判定をリセット

## 術 / 右クリック（16種）

### 錨撃 / `anchor`

- 錨を放ち、最初の敵を1.5秒間つなぎ止める
- 射程16ブロック / 近づくと錨へ踏み込む

お試し：`/otogi try anchor`

### 天狗の羽団扇 / `gale`

- 視線方向へ短くダッシュする
- 移動速度1.25 / CT5秒

お試し：`/otogi try gale`

### 惑乱 / `hack`

- 周囲10ブロックの敵の術を5秒間封じる
- 2秒間、敵の視界を3回揺さぶる

お試し：`/otogi try hack`

### 八尺様・呼び声 / `hasshaku`

- 右: 視線の先10mまでに、半径2.5mの予告領域を置く
- 1.2秒後に4HP。命中した相手の術を1.5秒封じる
- 照準は設置時に固定 / CT11秒

お試し：`/otogi try hasshaku`

### 鶴の恩返し / `mend`

- 自身を5HP回復する
- 全快なら不発 / CT12秒

お試し：`/otogi try mend`

### 鏡界 / `mirror`

- 前方に2秒間、攻撃を一度だけ返す鏡を張る
- 背後からの攻撃は防げない

お試し：`/otogi try mirror`

### 雷神・鳴神 / `narukami`

- 照準を固定し1秒後に射程12の雷閃
- 直線の幅0.45 / 7ダメージ・押し出し
- 火花の射線から回避可能 / CT12秒

お試し：`/otogi try narukami`

### 狐火・輪灯 / `nova`

- 周囲5ブロックに4ダメージ・押し出し
- 密着を崩す範囲術 / CT9秒

お試し：`/otogi try nova`

### 過速 / `overclock`

- 4秒間、自身の術のCT進行速度が2倍になる
- 効果中に術を使用すると効果時間が1秒短縮

お試し：`/otogi try overclock`

### 浄化 / `purge`

- 自身に付与されている状態異常をすべて解除する

お試し：`/otogi try purge`

### 断界 / `sever`

- 前方に3秒間、長さ6ブロックの境界を張る
- 触れた敵にダメージを与え、術を1秒間封じる

お試し：`/otogi try sever`

### 酒呑童子・鬼宴 / `shuten`

- 4秒間、具の直接ダメージが1.3倍
- 効果中は全被ダメージも1.25倍
- 術・範囲具は強化されない / CT13秒

お試し：`/otogi try shuten`

### 縁結び / `tether`

- 狙った敵と5秒間つながる（射程12ブロック）
- 距離が開くと引き寄せ、最後に鈍足を与える

お試し：`/otogi try tether`

### 帳 / `veil`

- その場に6秒間、半径5ブロックの帳を張る
- 帳の中では発光を解除 / 外への与ダメージ -20%

お試し：`/otogi try veil`

### 神隠し / `warp`

- 視線の先へ一瞬で移動する（射程30ブロック）
- 壁の手前で止まり、空中にも移動できる

お試し：`/otogi try warp`

### 雪女・白息 / `yukionna`

- 前方6ブロック・半角32度に冷気
- 3ダメージ / 命中した相手を3秒減速I
- 遮蔽物越しには届かない / CT9秒

お試し：`/otogi try yukionna`

## 具 / 武器（12種）

### 梓弓・鳴弦 / `azusa`

- 右クリック長押しで引き絞り、離して一射
- 溜めに応じて2〜7HP / 最大射程28m
- 射撃後1.2秒の隙 / 弾数無制限 / 左の近接攻撃なし

お試し：`/otogi try azusa`

### 輪刃 / `chakram`

- 通常攻撃で投擲武器を放ち、命中後に手元へ戻る
- 行きと帰りに一度ずつ命中。戻り刃の威力は低め
- 投擲中は通常攻撃できない

お試し：`/otogi try chakram`

### 長柄 / `halberd`

- 通常攻撃の射程が長く、命中した敵を弱くノックバックさせる
- しゃがみ＋左クリック：前方を貫く突き

お試し：`/otogi try halberd`

### 因幡・白兎 / `inaba`

- 左: 2.8mの扇形を薙ぐ、2.5HP
- 命中後3秒以内の右クリックで、視線方向へ跳ぶ
- 攻撃間隔0.8秒 / 跳躍CT7秒。空振りでは跳べない

お試し：`/otogi try inaba`

### 刀 / `katana`

- 間合いに入った相手を、ひと振りで斬る
- 左クリック：斬撃
- 右クリック / Shift＋左：0.6秒以内の前方の一撃を80%軽減（CT6秒）

お試し：`/otogi try katana`

### 口裂け・二口 / `kuchisake`

- 左: 3mの扇形に2.8HP。命中後2秒だけ追撃可能
- 右: 6mの細い直線の先頭に4.5HP、押し出し
- 攻撃間隔0.9秒 / 追撃CT6秒。右の空振りでも権利を消費

お試し：`/otogi try kuchisake`

### 灯籠 / `lantern`

- 手に持つと、近くに潜む相手の輪郭を照らす
- 右クリック：前方の相手の術を封じる
- 左クリック：灯籠を振る

お試し：`/otogi try lantern`

### 鬼の縫い針 / `needle`

- 射程8・幅0.25の直線攻撃、3ダメージ
- 先頭の敵だけに命中 / 間隔0.9秒

お試し：`/otogi try needle`

### 八岐大蛇・蛇骨 / `orochi`

- 左: 3.5mの突き、3HP。命中で牙を蓄える（最大3）
- 右: 牙を全消費し、周囲3.5mへ1＋牙数×1.5HP
- 攻撃間隔1秒 / 放出CT6秒。死亡で牙を失う

お試し：`/otogi try orochi`

### 細剣 / `rapier`

- 軽い突きを、素早く重ねる
- 背後への一撃は威力が上がる
- 同じ相手に突きを重ねると、次の一撃が貫通する
- 右クリック / Shift＋左：後方へ回避（CT6秒）

お試し：`/otogi try rapier`

### 書 / `tome`

- 狙った足元に、魔法陣を敷く
- 陣に触れた相手へ、鈍足と小ダメージ
- 左クリック：設置 / 同時に置ける陣の数には上限がある
- 右クリック / Shift＋左：1.5秒、前方ダメージを50%軽減（CT6秒）

お試し：`/otogi try tome`

### 護符 / `ward`

- 手に持つ間、一度だけ術のダメージを防ぐ
- 砕けた護符は時間が経つと戻る
- 左クリック：護符を振る
- 右クリック / Shift＋左：1.5秒、前方ダメージを50%軽減（CT6秒）

お試し：`/otogi try ward`
