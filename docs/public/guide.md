# 御伽の遊び方

「御伽 / Otogi」は、能力を組み合わせて戦うMinecraftの異能力PvPです。刀で間合いを詰める、弓で遠くを狙う、術で相手の動きを崩す。試合前に選んだビルドで戦い方が変わります。

このガイドは同梱の初期設定に合わせています。能力の数値や試合のルールはサーバーごとに変わるため、ゲーム内の説明も確認してください。

## まずは一試合

1. **ロビーを開く。** コンパス「御伽のメニュー」を右クリックするか、チャットで `/otogi` を実行します。
2. **ビルドを選ぶ。** 「ビルド」で使いたい能力を左クリックして追加します。外すときは右クリック。迷ったら、下のビルド例から始めてみてください。
3. **的で試す。** ビルド画面の「現在のビルドを試す」で、操作と間合いを確かめられます。練習を終えたら `/otogi try stop` で戻ります。
4. **参加待機に入る。** ロビーの「試合に参加待機」を押します。コマンドなら `/otogi game join`。待機は次の試合への参加予約です。
5. **運営の開始を待つ。** マップとモードは運営が選びます。開始すると戦場へ移動し、選んだ能力のアイテムが配られます。

> 試合は自動では始まりません。通常は2人以上、デュオは4人以上の偶数人数が必要です。試合中の途中参加はできません。

## 操作を覚える

数字キーやホイールでアイテムを持ち替え、そのアイテムを使います。マウスボタンやしゃがみキーを変更している場合は、自分の操作設定に読み替えてください。

| 持っているもの・画面 | 操作 | 起きること |
| --- | --- | --- |
| メニューのコンパス | 右クリック | ロビーを開く |
| ビルド選択画面 | 左クリック / 右クリック | 能力を追加 / 選択を解除 |
| 多くの具 | 左クリック | 通常攻撃。持ち替えても攻撃の待ち時間は共通 |
| 術のアイテム | 右クリック | 術を発動。使うとCTが発生 |
| 式・相のアイテム | 持ち替えて状態を確認 | 常時効果・自動発動。クリックで発動する必要はない |
| 刀・書・護符 | 右クリック、またはしゃがみ＋左クリック | 前方を防御。背後からの攻撃には注意 |
| 細剣 | 右クリック、またはしゃがみ＋左クリック | 後方へ回避 |
| 長柄 | しゃがみ＋左クリック | 前方へ突く |
| 灯籠 | 右クリック | 前方の相手の術を封じる |
| 梓弓・鳴弦 | 右クリックを長押し → 離す | 引き絞って射撃。左クリックの近接攻撃はない |
| お試しの時計 / バリア | 右クリック | 練習をリセット / 終了 |

具には独自の追加操作を持つものがあります。たとえば「因幡・白兎」は命中後の右クリックで跳躍し、「口裂け・二口」は追撃します。詳しくはアイテムの説明や[能力図鑑](abilities.md)を確認してください。

## ビルドを組む

ビルドは試合で使う能力のセットです。初期設定は**合計5枠、式は1つまで**。相・術・具は枠の範囲で自由に選べます。4分類すべてを入れる必要はありません。

| 分類 | 役割 | 例 |
| --- | --- | --- |
| 式 | 体力・移動速度などを変える常時効果 | 生気、韋駄天、天女の羽衣 |
| 相 | 被弾や命中など、条件を満たすと自動発動 | 応報、鬼の血脈、浦島・玉手箱 |
| 術 | 右クリックで使う移動・攻撃・妨害・回復 | 神隠し、雪女・白息、鶴の恩返し |
| 具 | 手に持って攻撃する武器 | 刀、細剣、梓弓・鳴弦 |

上段の分類ボタンで候補を絞れます。選択済みの能力は通常の一覧でバリア表示になり、「選択中だけ」では元のアイコンで確認できます。併用できない組み合わせは、選べない理由が画面に出ます。

空のビルドで試合に入ると能力がランダムに割り当てられます。一部だけ選んだビルドの空き枠を、自動で埋める仕組みではありません。通常攻撃を使いたいときは、具を1つ以上選びましょう。試合中はビルドを変更できません。

### 刀から始める5枠

**生気 / 応報 / 神隠し / 鶴の恩返し / 刀**

刀の左クリックで攻撃し、相手の一撃には右クリックの前方防御を合わせます。生気で体力を増やし、削られたら鶴の恩返しで回復。神隠しは近づくときにも離れるときにも使えます。応報は先手を取られたときに自動で働きます。

最初は攻撃と防御だけを的で練習し、慣れてから術の持ち替えを加えると操作を覚えやすくなります。

### 弓で距離を取る5枠

**天女の羽衣 / 浦島・玉手箱 / 天狗の羽団扇 / 雪女・白息 / 梓弓・鳴弦**

梓弓を引き絞って射撃し、相手が近づいたら白息で減速させ、羽団扇で距離を取ります。玉手箱は攻防から離れたときの回復を助けます。羽衣は移動速度が上がる代わりに受けるダメージも増えるため、近距離での打ち合いに注意してください。

> ここで紹介するのは操作を覚えるための例です。強さの順位ではありません。好みの具を決め、足りない移動・回復・妨害を足してみましょう。

## 戦闘と画面の見方

基礎体力は初期設定で**40HP＝20ハート**。式などの効果で最大値が変わります。CTはクールダウン、つまり次に使えるまでの待ち時間です。

- **攻撃の届く範囲**：斬撃は前方の扇形、突きは直線など、具によって違います。壁などの遮蔽物で止まり、背後の相手へ自動で当たることはありません。
- **CT表示**：初期設定はアイテム上のマイクラ標準表示です。ロビー上段の時計で、文字のアクションバー表示にも切り替えられます。設定は自分だけに適用されます。
- **弓の溜め**：引き絞っている間は溜め具合を表示します。約1秒で最大溜め。梓弓の矢は放物線で飛び、溜めに応じて威力が変わります。
- **サイドバーとボスバー**：目標、自分の成績、順位、残り時間などを表示します。拠点制圧では拠点の状況も確認できます。
- **戦場の境界**：境界面に近づくと赤い粒子が出ます。場外への転落は死亡として扱われます。
- **相手の見つけ方**：試合中はネームタグを隠します。ロケーターバーも無効になるため、姿や音、能力の演出から位置を探しましょう。

死亡後は通常5秒待って復活します。復活直後の加護は通常3秒で、攻撃や術の使用で解除されます。残機を使い切った残機戦では、その試合は観戦に回ります。

## 6つの対戦モード

表の人数・数値は初期設定です。各試合の目標はゲーム内でも表示されます。デュオ以外は個人戦です。

| モード / ID | 人数 | 勝ち方 | 制限時間 |
| --- | --- | --- | --- |
| 乱戦 / `ffa` | 2人以上 | 10キル先取 | 10分 |
| 残機戦 / `last_stand` | 2人以上 | 残機3。最後まで生き残る | 10分 |
| 時間制乱戦 / `timed` | 2人以上 | 終了時に最も多く撃破する | 3分 |
| 賞金争奪 / `bounty` | 2人以上 | 20点先取。連続撃破中の相手は最大4点 | 10分 |
| 拠点制圧 / `king_of_hill` | 2人以上 | 拠点を単独で制圧し、60点先取 | 10分 |
| デュオ / `duo` | 4人以上の偶数 | ランダムな2人組で、チーム合計20キル先取 | 10分 |

乱戦・時間制乱戦の時間切れは撃破数、次に死亡数の少なさで判定します。残機戦は残機、次に撃破数。賞金争奪・拠点制圧・デュオはそれぞれの得点で判定し、勝敗が並べば引き分けになります。

拠点制圧は拠点内に自分だけがいると毎秒1点。複数人が入っている間は加点されません。拠点の判定は水平方向の半径と、中心から上下3ブロック以内です。

デュオの相方は毎試合ランダムです。サイドバーで相方とチーム得点、Tab一覧でチーム番号と色を確認できます。味方へのダメージやノックバックは無効で、弓矢は味方を通過します。相方が退出しても試合は続きます。

## 試合の前に練習する

ロビーの「術・具のお試し」か `/otogi try` で、登録済みの術・具を選べます。単体のお試しはビルドを組まなくても使えます。

| 練習 | 始め方 | 的と体力 |
| --- | --- | --- |
| 術・具を1つ試す | 一覧から選ぶ、または `/otogi try azusa` など | 的は反撃しない。自分は体力半分から開始 |
| 今のビルドを試す | ビルド画面の的、または `/otogi try build` | 自分は全快。的は近距離で2秒ごとに2HPの反撃 |

ビルドのお試しには、能力を1つ以上選ぶ必要があります。回復・妨害の使いどころや、相・式を含む組み合わせもここで確かめられます。

`/otogi try reset` で体力・CT・的をリセット、`/otogi try stop` で終了します。時計とバリアが配られている場合は右クリックでも操作できます。

お試しは現在地の周囲を使います。2分経過、開始地点から48ブロック以上の移動、ワールド移動などで終了します。持ち物や位置は開始前に戻り、練習での撃破や死亡は戦績に加算されません。

## よく使うコマンド

| コマンド | 用途 |
| --- | --- |
| `/otogi` | ロビーを開く |
| `/otogi build` | ビルドを選ぶ |
| `/otogi build show` | 選択中の能力を確認 |
| `/otogi build reset` | ビルドの選択をすべて外す |
| `/otogi try` | 術・具のお試し一覧 |
| `/otogi try build` | 選択中のビルドを試す |
| `/otogi try reset` | 練習をリセット |
| `/otogi try stop` | 練習を終了 |
| `/otogi game join` | 次の試合へ参加待機 |
| `/otogi game leave` | 待機の取り消し、または試合から退出 |
| `/otogi game status` | 試合の状況を確認 |
| `/otogi game modes` | モードと勝利条件を確認 |
| `/otogi stats` | 通算撃破・死亡・試合数・勝利数・K/Dを確認 |
| `/otogi settings cooldown minecraft` | CTをアイテム上に表示 |
| `/otogi settings cooldown actionbar` | CTを文字で表示 |

## 困ったときは

### コンパスが見当たらない

まず `/otogi` を使ってください。コンパスは試合外でインベントリの空き枠に配られます。満杯なら1枠空けます。

### 能力を選べない

枠が埋まっている、式をすでに1つ選んでいる、併用不可の能力が入っている可能性があります。表示された理由を確認し、外したい能力を右クリックしてください。試合中は変更できません。

### 攻撃・術が使えない

使いたいアイテムを手に持っているか、CTが終わっているかを確認してください。復活待ちや観戦中は使えません。術を封じる効果を受けている場合もあります。弓は右クリックを長押しして、離すと撃てます。

### 待機しても始まらない

開始は運営が行います。マップの登録と選択、人数、スポーン地点の数が必要です。デュオは4人以上の偶数人数で待機してください。

### 試合から抜けたい

`/otogi game leave` を使います。途中退出した試合には戻れず、その試合での勝利扱いにもなりません。試合前の持ち物や体力、位置などは復元されます。

### 練習の終了アイテムがない

`/otogi try stop` を使ってください。枠数を増やしたサーバーなどでは、能力アイテムを優先して時計やバリアを配らない場合があります。
